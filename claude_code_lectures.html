1.6% brain, 98.4% harness.

A chapter-by-chapter tour of “Dive into Claude Code: The Design Space of Today's and Future AI Agent Systems” (Liu, Zhao, Shang & Shen, MBZUAI VILA Lab, 2026) — a source-level analysis of Claude Code's publicly available TypeScript, traced from five human values to specific implementation choices.

The paper's central finding: the core of Claude Code is a simple while-loop that calls the model, runs tools, and repeats. Almost none of the code is "agent brain" — a community estimate puts ~1.6% of the codebase as AI decision logic and ~98.4% as operational infrastructure. The architecture's real substance is the systems built around that loop: a seven-mode permission system with an ML classifier, a five-layer context-compaction pipeline, four extensibility mechanisms, isolated subagent delegation, and append-only session storage.

# The kernel the whole paper hangs off — queryLoop() in query.ts:
while not stopped:
    context = assemble(system, tools, history, hooks)  # shape what the model sees
    response = model(context, tools)              # the model only decides
    if response.text_only(): break            # no tool_use -> turn done
    for call in response.tool_uses():
        if permitted(call):                # deny-first gate + hooks + classifier
            history.append(execute(call))    # the harness acts & reports

Throughout, the authors thread one running example — “Fix the failing test in auth.test.ts” — through every subsystem (Sections 3–9), and then calibrate the design by contrasting it with OpenClaw, an independent open-source multi-channel gateway that answers the same questions from a very different deployment context.

One loop, a whole operating system around it

The kernel is tiny; the harness is the architecture.

Read together, the twelve chapters describe a coherent design point: maximal model autonomy inside a rich deterministic harness. Safety, context, and extensibility are each built as graduated stacks of independent mechanisms; state is append-only for auditability; and the model is trusted to decide while the harness enforces. The open question the paper leaves us with: as frontier models converge, the quality of that harness — not the model — becomes the differentiator, and whether such a harness can also preserve long-term human capability is still unanswered.
